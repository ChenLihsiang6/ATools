## ✨ 项目简介
ATools 是专为《永恒之塔2》台服制作的桌面工具箱。
软件**完全免费，全部功能无锁定、无广告、无捆绑、无任何内购**。
所有数据取自官方公开API与玩家社区公开资料，不抓游戏数据包、不读取游戏进程内存，安全合规。

> ⚠️ 开发状态：DPS战斗解析模块仍在开发中，暂未上线。

## 📦 核心功能
- 🕒 日常助手：服务器时间与重置倒计时、每日/每周任务打卡清单、版本活动提醒
- 👤 角色查询 & 角色对比：输入角色名+服务器读取装备、属性信息
- 📖 副本攻略手册、基纳物价计算器、日常任务打卡等实用工具
